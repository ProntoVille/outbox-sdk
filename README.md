# @prontoville/outbox

Outbox TypeScript SDK for server-side transactional email. Supports Node.js 20+, ESM and CommonJS. Zero runtime dependencies.

## Installation

```sh
npm install @prontoville/outbox
```

This is the intended npm package name. Registry publication must be completed before this command will work.

Create a platform account, verify your mailbox, enable managed sending or connect a provider, verify your sender domain, then create an API key in Developers. Store the key and your platform's HTTPS origin in your backend's secret manager as `MAIL_API_KEY` and `MAIL_BASE_URL`.

```ts
import { Outbox, OutboxApiError } from '@prontoville/outbox';

const mail = new Outbox({
  apiKey: process.env.MAIL_API_KEY!,
  baseUrl: process.env.MAIL_BASE_URL!,
});

const message = await mail.send({
  from: 'accounts@your-verified-domain.com',
  fromName: 'Your app',
  to: 'customer@example.com',
  subject: 'Reset your password',
  text: 'Use the expiring, single-use reset URL generated by your application.',
}, { idempotencyKey: 'password-reset:unique-request-id' });

const status = await mail.getMessage(message.id);
```

CommonJS: `const { Outbox } = require('@prontoville/outbox');`.

Your application creates and consumes password-reset tokens; the SDK sends their email. Never put API keys in browser/mobile bundles or log reset URLs. Use plain text or escape untrusted values included in HTML.

`send()` means accepted into the queue, not delivered. Use `getMessage()` or signed platform webhooks to track delivery. `OutboxApiError.status` contains the API HTTP status. Requests time out after 10 seconds (configure `timeoutMs`); network failures propagate. Sends are not automatically retried: a timeout can occur after acceptance. Retry with the **same idempotency key** for the same message; use a fresh key for a new request.

You can pass `template` and `data` instead of subject/body. Sender verification, routing, billing and suppression rules are enforced by the platform, including when using this client.

## Development and releases

```sh
npm ci
npm test
npm pack --dry-run
```

Source: `src/index.ts`. Build outputs: ESM, CommonJS, declarations and source maps in `dist/`. No credentials belong in this repository. Publish public releases with `npm publish --access public`; for subsequent automated releases configure npm trusted publishing for `.github/workflows/publish.yml`, then dispatch it after updating the version.
